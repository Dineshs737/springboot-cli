## ✨ Features

- **`springcli new`** — Scaffold a new Spring Boot project in seconds
- **`springcli add`** — Add dependencies with auto-resolution from start.spring.io
- **`springcli remove`** — Remove dependencies cleanly from pom.xml / build.gradle
- **`springcli list`** — Browse & search all available Spring Boot starters
- **`springcli security`** — Configure Spring Security with JWT/OAuth2 in one command

## 📦 Installation

### Download Binary

Download the latest release for your platform from the [Releases](https://github.com/YOUR-ORG/springcli/releases) page.

```bash
# Linux (amd64)
curl -Lo springcli https://github.com/YOUR-ORG/springcli/releases/latest/download/springcli-linux-amd64
chmod +x springcli
sudo mv springcli /usr/local/bin/

# macOS (Apple Silicon)
curl -Lo springcli https://github.com/YOUR-ORG/springcli/releases/latest/download/springcli-darwin-arm64
chmod +x springcli
sudo mv springcli /usr/local/bin/
```

### Build from Source

```bash
git clone https://github.com/YOUR-ORG/springcli.git
cd springcli
go build -o springcli .
```

### Go Install

```bash
go install github.com/springcli/springcli@latest
```

## 🚀 Command Reference

### `springcli new` — Create a new project

```bash
# Basic usage
springcli new my-api

# With all options
springcli new my-service \
  --language kotlin \
  --type gradle-kotlin \
  --java 21 \
  --group com.acme \
  --artifact shop-service \
  --deps web,jpa,security,actuator
```

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--group` | `-g` | `com.example` | Maven group ID |
| `--artifact` | `-a` | project name | Maven artifact ID |
| `--description` | `-d` | `Generated by SpringCLI` | Project description |
| `--language` | `-l` | `java` | `java` / `kotlin` / `groovy` |
| `--type` | `-t` | `maven` | `maven` / `gradle` / `gradle-kotlin` |
| `--boot` | `-b` | `3.2.3` | Spring Boot version |
| `--java` | `-j` | `17` | Java version |
| `--packaging` | | `jar` | `jar` / `war` |
| `--deps` | | | Comma-separated dependency IDs |

### `springcli add` — Add dependencies

```bash
springcli add web
springcli add jpa postgresql redis kafka
springcli add web --dir ./my-project
```

### `springcli remove` — Remove dependencies

```bash
springcli remove web
springcli rm jpa redis              # 'rm' is an alias
springcli remove spring-boot-starter-web  # full artifact ID works too
```

### `springcli list` — Browse dependencies

```bash
springcli list                          # all deps grouped by category
springcli list --search kafka           # fuzzy search
springcli list --category Security      # filter by category
springcli list --installed              # show what's in current project
springcli list --installed --dir ./app
```

### `springcli security` — Configure Spring Security

```bash
springcli security                              # basic HTTP security
springcli security --jwt                        # add JWT deps (jjwt 0.12.5)
springcli security --oauth2                     # add OAuth2 resource server
springcli security --jwt --generate-config      # add deps + generate SecurityConfig
springcli security --oauth2 --generate-config   # add deps + generate SecurityConfig
```

## 🏗️ Architecture

```
springcli/
├── main.go                    Entry point, version injection
├── cmd/                       Cobra CLI commands
│   ├── root.go                Root command + banner
│   ├── new.go                 Project scaffolding
│   ├── add.go                 Dependency addition
│   ├── remove.go              Dependency removal
│   ├── list.go                Dependency browsing
│   └── security.go            Security configuration
├── internal/
│   ├── initializr/            Spring Initializr API client
│   │   ├── client.go          HTTP client with caching
│   │   └── models.go          API response structs
│   ├── maven/
│   │   └── parser.go          pom.xml DOM manipulation (etree)
│   ├── gradle/
│   │   └── parser.go          build.gradle text manipulation
│   ├── project/
│   │   ├── config.go          ProjectConfig struct
│   │   └── detector.go        Build system detection
│   └── ui/
│       └── printer.go         Colored output, tables, spinner
└── testdata/                  Test fixtures
```

## 🔄 How It Works

```
┌──────────────┐     HTTP/JSON      ┌────────────────────┐
│  SpringCLI   │ ◄─────────────────► │  start.spring.io   │
│  (Go binary) │                     │  Initializr API    │
└──────┬───────┘                     └────────────────────┘
       │
       │  Read/Write
       ▼
┌─────────────────┐
│  pom.xml        │
│  build.gradle   │
│  build.gradle.kts│
└─────────────────┘
```

1. **`new`**: Calls Spring Initializr API → downloads ZIP → extracts to local directory
2. **`add`**: Fetches metadata → resolves dependency coordinates → patches build file
3. **`remove`**: Parses build file → finds matching dependency → removes it cleanly
4. **`list`**: Fetches metadata → displays as styled tables with categories
5. **`security`**: Adds security deps → optionally generates SecurityConfig source file
